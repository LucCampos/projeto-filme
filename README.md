# Atividade 02 - DESENVOLVENDO UMA PÁGINA WEB: PACIFIC RIM
A página desenvolvida prossegue em trazer informações breve sobre o filme Paciic Rim, com o intuito de testar os conhecimentos aprendidos sobre a linguagem de marcação (HTML).

## 🎥Informações sobre o projeto🎥
Filme escolhido: Pacific Rim (2013)

* Aluno: Lucas de Oliveira Campos
* Turma: 1IE
* Data: 11/08/2026

## 💻Sobre a Atividade💻
A atividade foi concluida utilizando a linguagem de marcação de texto (HTML) em sua quinta versão, utilizando os requisitos demandados pelo professor, onde a página deve conter:

* A tag "title" deve ser utilizada.
* A tag "h1" deve ser utilizada.
* Uma imagem deve ser acrescentada relacionada ao filme escolhido.
* A tag "h2" deve ser utilizada para a demonstração de informações básicas do filme.
* A tag "p" deve ser utilizada para a sinopse do filme.
* A tag "a" deve ser utilizada para um link com um site contendo mais informações.

## 📤 Tecnologias Utilizadas 📤
A atividade foi feita utilizando o HTML 5 e o GitHub Desktop.

## 💡Objetivo da Atividade💡
O principal objetivo da atividade foi o teste dos conhecimentos de linguagem de marcação aprendido durante as aulas da instituição do Senai.
